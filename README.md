# DomainIntel

**注：当前为开发版本，尚未完成开发，暂无exe文件**

**注：限于人力资源和算法能力有限，工具中给出的风险等级仅作参考，请以专业人员的判断为准**

> 批量域名情报采集、风险研判与滥用举报工具

输入一批域名，自动完成：DNS / WHOIS / HTTP / 证书 / IP 全维度采集 → 风险分级 → 载荷提取与沙箱验证 → 生成报告 → 生成并发送滥用举报邮件。

有图形界面和命令行两套入口。

---

## 特性

| 能力 | 说明 |
|---|---|
| **权威验证** | 直接查询注册局权威服务器，绕开本地缓存，准确判断域名是否真实存在 |
| **全维采集** | DNS 8 类记录、WHOIS 全字段、HTTP 响应、TLS 证书、IP 归属、端口、同 IP 反查 |
| **动态解析检测** | 多 DNS 多轮采样，统计 IP 池，识别 CDN 与轮换调度 |
| **载荷提取** | 直链可执行文件、跳转网关 base64 解码、网盘分发识别、下载页二层抓取 |
| **风险评分** | 分层证据模型，官方站 0 分、仿冒站 85-100 分，附可读判定理由 |
| **跨域名关联** | 同模板 / 同邮箱 / 同 IP / 同证书自动归并 |
| **沙箱验证** | 下载样本 → SHA256 → VirusTotal 查询 / 上传 → 自动清理 |
| **报告输出** | Word / Excel / Markdown / JSON |
| **滥用举报** | 按注册商分组生成举报邮件，自动推导 abuse 邮箱，审核后一键发送 |

## 快速开始

### 1. 安装依赖

```bash
python -m pip install -r requirements.txt
```

需要 Python 3.9+。

### 2. 初始化配置

```bash
python setup_config.py
```

然后编辑 `core/config.json`，至少填 VirusTotal API Key：

```json
{
  "virustotal": {
    "api_key": "你的key"
  }
}
```

也可以用环境变量（优先级更高）：

```bash
set VT_API_KEY=xxx
set DI_SENDER=your@mail.com
set DI_MAIL_PASSWORD=xxx
```

### 3. 运行

**图形界面**

```bash
python gui.py
```

或双击 `启动.bat`。

**命令行**

```bash
python cli.py domains.txt
```

或双击 `命令行.bat`。

## 命令行用法

```bash
# 基础
python cli.py domains.txt
python cli.py -d "a.com,b.com" -w 8

# 可选开关
python cli.py domains.txt --no-payload --no-mail     # 只探测，不做载荷和邮件
python cli.py domains.txt --send                     # 生成后直接发邮件
python cli.py domains.txt --multi-node               # 加多节点 CDN 探测
python cli.py domains.txt --no-anim                  # 关动画（重定向到文件）
```

| 参数 | 说明 |
|---|---|
| `domains` / `-d` | 域名列表文件，或逗号分隔的域名 |
| `-o` | 输出目录（默认 `output/`） |
| `-w` | 并发数（默认 6） |
| `--limit` | 最多处理多少个 |
| `--no-anim` | 关闭动态动画 |
| `--no-auth` / `--no-multi` / `--no-cert` / `--no-port` | 跳过对应采集 |
| `--reverse-ip` / `--subdomain` / `--multi-node` | 启用慢速采集项 |
| `--no-payload` | 跳过载荷分析 |
| `--no-upload` | VT 无记录时不自动上传 |
| `--no-mail` | 不生成举报邮件 |
| `--send` | 生成后直接进入发送流程 |
| `--interval` | 邮件发送间隔秒数 |

## 风险评分模型

分两层：**证据分级累加 + 负分校正**。

### 强证据

| 判据 | 分值 |
|---|---|
| 注册邮箱命中已知黑产主体 | +50 |
| 与已知恶意域名同源（同邮箱/IP/模板）| +50 |
| 页面指向外站可执行文件 | +35 |
| 域名注册 ≤ 30 天 | +30 |
| 下载页内指向可执行文件 | +30 |
| 品牌仿冒（编辑距离 ≤2 或品牌词+前后缀）| +25 |
| 注册后 24h 内签发证书 | +25 |
| 页面引导至网盘下载 | +25 |
| 页面引用对象存储桶 | +25 |
| 标题含品牌名但域名非官方 | +25 |
| 跳转网关分发 | +20 |
| 与同批域名共用证书 | +15 |
| 页面体积大 + 域名新（整站克隆）| +15 |
| 避风港注册商 | +15 |
| 引用品牌真官网伪装可信度 | +15 |
| 含 ICP 备案号 | +10 |
| 诱导下载文案 | +10 |

### 减分

| 判据 | 分值 |
|---|---|
| 域名即品牌官方域名 | -30 |
| 域名存在 ≥ 5 年 | -20 |
| 正规企业级注册商 | -10 |

### 中性（只展示不计分）

DNS 动态解析、Cloudflare / WAF、注册人隐私保护、高风险 TLD、无 MX/TXT —— 这些项**官方站同样命中**，没有区分度。

### 分级

```
≥70  高危     45-69  可疑     20-44  低危     <20  正常
```

### 实测对照

| 域名 | 类型 | 分数 |
|---|---|---|

| nexosmods.com | 仿冒 | 100 高危 |
| dismplus.com | 仿冒 | 100 高危 |
| typora.io | 官方 | 0 正常 |

`core/brands.json` 维护知名品牌官方域名，用于相似度判定、官方白名单、真官网引用检测。

```json
{"name": "Dism++", "official": ["chuyu.me"], "aliases": ["dism", "dism++"]}
```

遇到新品牌直接追加即可，无需改代码。

## 载荷提取规则

四层优先级：

```
1. 直链可执行文件   .exe/.zip/.rar/.7z/.msi/.apk/.dmg    → 高分
2. 跳转网关         tj.xxx.com/go.php?u=<base64>          → 自动解码
3. 网盘分享         百度 / UC / 夸克 / 迅雷 / 阿里 / 天翼 → 记录平台名
4. 下载页           站内 /download.html                   → 二层抓取真实载荷
```

注意：`/download.html` 这类是**页面**不是载荷，只给弱提示分。

## VirusTotal 集成

```
下载 → SHA256 → 查缓存 → 查 API → 无记录则上传 → 轮询结果 → 删除本地样本
```

**配额管理**：内置令牌桶（默认 4 次/分钟、500 次/天），本地缓存避免重复查询。

免费公共 API 限制：

| 项 | 限制 |
|---|---|
| 每分钟 | 4 次 |
| 每天 | 500 次 |
| 单文件 | 32 MB 直传，650 MB 走 upload_url |

**安全提示**：下载目录 `output/samples/` 必须加入杀软白名单；不要手动解压样本；分析完成后工具会自动删除。

## 滥用举报

1. 只处理高危 / 可疑域名
2. 按注册商分组（同注册商合并成一封）
3. abuse 邮箱推导优先级：WHOIS 字段 → 已知映射表 → 注册商域名拼接
4. 每个域名生成专属证据链（仿冒、载荷、网盘、网关、VT 检测结果）
5. 草稿存到 `output/abuse_drafts/<时间戳>/`
6. 审核窗口可逐封查看、编辑、发送

邮件正文示例：

```

我方在网络安全监测中发现，贵司管理的域名 dism.pro 存在以下违规行为。

1. 仿冒侵权
   域名主体与品牌词「dism」完全相同

2. 网盘分发
   该站将下载引导至网盘：[夸克网盘] https://pan.quark.cn/s/6e79b64d4074

3. 恶意软件实锤（VirusTotal）
   该站分发的文件「Nexus.zip」（SHA256: 42d174cd...）经 VirusTotal
   多引擎检测，12/74 引擎判定为恶意，威胁类型：trojan.cryp/ccmw

4. 注册与解析信息

```

## 注意事项

- 单次建议 ≤ 500 个域名，每个约 15-30 秒
- 并发默认 6，过高容易被目标站或 DNS 限流
- 所有数据来自公开 DNS / WHOIS / HTTP / 证书，不做漏洞利用或暴力破解
- 恶意样本不要解压执行，先算哈希再送沙箱
- 举报邮件发出前建议先发一封给自己测试格式
- `core/config.json` 含 API Key，已在 `.gitignore` 中排除
